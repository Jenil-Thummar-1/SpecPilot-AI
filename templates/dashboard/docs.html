Platform Help & Setup Guides

Quick reference instructions detailing setup, prompt customizations, and credentials overrides.

1. Configuring Gemini API credentials

SpecPilot AI queries Google's Gemini LLMs to write specifications. By default, the system loads the key from the GEMINI_API_KEY environment variable in your root directory. Alternatively, developers can specify a key inside the System Settings page to override it for their active session.

2. Executing Workflow steps

Navigate to any project workspace workspace. If previous steps are COMPLETED, the subsequent stage button becomes active. Clicking "Run Planning Step" initiates the active Agent's task. Once execution concludes, the spec status enters a "Pending Review" lock state.

3. Reviewing & Editing Specifications

Click the generated specification block or select "View & Review". You can:

  • Approve: Unlocks the next planning stage.
  • Reject: Flags the stage as FAILED, allowing you to run regeneration.
  • Edit: Modifies the specification text manually, which saves the update as an incremented version draft.
