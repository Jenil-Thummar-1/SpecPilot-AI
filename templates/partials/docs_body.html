System Reference Guide

Learn how to configure, execute, audit, and export systems inside SpecPilot AI.

1. Introduction to SpecPilot AI

SpecPilot AI utilizes hierarchical LLM networks to compile complete project blueprints from simple, unstructured descriptions. The platform coordinates multiple specialized agents (Architects, Planners, and Quality specialists) across a 15-stage planning lifecycle.

2. Gemini API Credentials Configuration

To initiate agent runs, the platform requires standard access keys to Google's Gemini models. By default, the application checks your root .env file.

Create a file named .env in your root directory and define the following key: 

# Root .env configuration
GEMINI_API_KEY=your_gemini_api_key_here

Alternatively, developers can configure the credentials on the **System Settings** page within the workspace, which overrides the environmental variable for the active session.

3. Executing the FSM Pipeline

When inside a project workspace, SpecPilot renders a stage sequence tracker. Clicking **"Run Planning Step"** initiates the active agent.

The active agent compiles its specific segment (e.g. Entity Models) by matching context files against strict system instructions. Once finished, the segment enters a locked **Pending Review** state where you can either:

  • Approve: Confirms the layout and unlocks the subsequent planning stage.
  • Reject: Sets the stage to FAILED, allowing you to re-run generation with modified scopes.
  • Edit: Directly edit the draft text manually. Saving edits automatically locks a new sub-version.

4. Version Snapshots

Every stage in SpecPilot AI keeps a historical timeline of drafts. Every manual edit, rejection re-run, or parameter change increments the sub-version index. Use the snapshot dropdown inside the editing workspace to roll back to previous drafts at any time.

5. Exporting Assets

After completing the final stage, clicking the export panel compiles the entire state history into structured, portable artifacts: 

{
  "project_id": "proj_01j7h",
  "version": "1.4.0",
  "compiled_at": "2026-07-06T14:55:00Z",
  "stages": {
    "prd": "...markdown description...",
    "database": "...sql code block...",
    "api_definition": "...openapi yaml..."
  }
}

You can download these files as unified markdown textbooks, structured JSON configuration records, or a zipped archive containing independent code documents.
